### 4. Environment Variables to Set in Render

After deployment, set these in Render dashboard for the web service:

**Required (sync: false in render.yaml):**
- `APP_URL` - Will be `https://YOUR_SERVICE_NAME.onrender.com`
- `RESEND_API_KEY` - Your Resend API key for emails
- `MSG91_AUTH_KEY` - MSG91 auth key for SMS
- `MSG91_TEMPLATE_ID` - MSG91 template ID
- `S3_ENDPOINT` - S3-compatible endpoint URL
- `S3_BUCKET` - Bucket name
- `S3_ACCESS_KEY_ID` - S3 access key
- `S3_SECRET_ACCESS_KEY` - S3 secret key
- `S3_PUBLIC_URL` - Public URL for S3 assets
- `RAZORPAY_KEY_ID` - Razorpay key ID
- `RAZORPAY_KEY_SECRET` - Razorpay secret
- `RAZORPAY_WEBHOOK_SECRET` - Razorpay webhook secret
- `SENTRY_DSN` - (Optional) Sentry DSN for error tracking

**Auto-generated by Render:**
- `SESSION_SECRET` - Auto-generated
- `CRON_SECRET` - Auto-generated
- `DATABASE_URL` - From eventsliner-db
- `REDIS_URL` - From eventsliner-redis
